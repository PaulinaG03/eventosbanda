# Plataforma web de organización de eventos para una banda

Proyecto integrador de la materia **Formulación de proyectos de software**, Universidad Politécnica de Pénjamo (Ingeniería en Tecnologías de la Información e Innovación Digital, grupo 7 "A").

## Descripción

Página web para una banda musical donde el manager agenda los conciertos y los integrantes los reciben automáticamente en sus calendarios mediante un enlace iCal. Así todos saben dónde, cuándo y a qué hora es cada presentación.

## Metodología y herramientas

- **Metodología:** Scrum (enfoque ágil/híbrido), 5 semanas y 3 sprints de una semana.
- **Gestión del proyecto:** Jira
- **Interfaz:** React
- **Base de datos:** Neon
- **Calendario:** enlace iCal
- **Código:** GitHub
- **Diseño:** Figma / Canva

## Flujo de trabajo en Git

1. No se trabaja directamente en `main`.
2. Cada cambio se sube en una rama nueva con un Pull Request.
3. Otro integrante revisa y aprueba antes de hacer el merge.
4. Nunca se suben contraseñas, claves ni archivos `.env`.
